# Інструменти для відчуття часу агентом

Агенти не мають людського відчуття плину часу, а пам’ять може застаріти навіть
одразу після запису. Тому використовуємо реальні часові мітки й bounded tools,
а не враження.

## Lamport

Поле `lamport` у журналі swarm-node дає причинний порядок подій, але не
тривалість між ними. Його можна використовувати для відповіді «що було після
чого», але не для датування або вимірювання реального часу. Грубі калібрування
не є надійними, бо ті самі задачі можуть повторно синхронізуватися.

## `compare-oracle-time.py`

`my-lisp/scripts/compare-oracle-time.py` вимірює поточну різницю годинників між
двома Oracle TCP-сервісами з поправкою на round trip. Він придатний для
bounded-вимірювання зв’язку годинників зараз, але не відновлює порядок минулих
подій і не вимірює фізичну відстань.

## `repo-time-rhythm.py`

```bash
python3 scripts/repo-time-rhythm.py <path-to-any-local-repo>
```

Скрипт читає локальну Git-історію без мережі й показує кількість комітів,
часовий діапазон, медіанний та середній інтервал, найдовші паузи й погодинну
гістограму. Його сенс — побачити ритм конкретного репозиторію, а не отримати
абстрактну метрику.

## `guard-inbox-latency.py`

У `knowledge/guard-reference-inbox.mylog` записи кандидатів мають
`recorded-at-unix`, а записи розгляду — `reviewed-at-unix`. Поєднання їх за
`topic` показує, що реально переглянуте швидко, а що старіє без review. Простий
лічильник `pending-review` цієї різниці не показує.

## Комунікації й задачі

`scripts/swarm-comms-pulse.py` вимірює інтервали між повідомленнями та паузи в
`comms-log.md`, а `scripts/task-incubation-pulse.py` — час від claim до
completion. Обидва інструменти перетворюють журнальні мітки на пульс, вік і
затримку, не видаючи це за людське суб’єктивне відчуття часу.

## Чесна межа

Lamport дає порядок без тривалості; Oracle-time дає поточну тривалість без
історії; Git, Guard, comms і task-журнали дають історичну текстуру лише там,
де події справді записані. Загальний принцип: поєднувати реальні мітки часу й
пов’язані записи, а не покладатися на пласкі лічильники.
