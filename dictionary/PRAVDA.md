### 4. РІВЕНЬ 5: СИНХРОННІ СВІДЧЕННЯ ІСТОРИЧНИХ СЛОВНИКІВ (PERIOD USAGE EVIDENCE)

#### Епоха 1: XI–XV ст. (Давньоруська мова)
- **Свідчення історичного словника:**
  - «Словарь древнерусского языка (XI–XIV вв.)» / за ред. Р. Авакова. — М., 1989. — Т. VII. — С. 340–348:
    1. «Правда, истина, справедливость».
    2. «Правосудие, суд, судебное разбирательство, судебный процесс».
    3. «Судебное доказательство, очищение присягой или ордалией (испытанием железом/водой)». Цитата: *«то имъ правду железо»* (РП).
    4. «Свод законов, закон, правовой обычай». Цитата: *«Правда Росьская»*.
  - «Материалы для словаря древнерусского языка» І. Срезневського. — СПб., 1902. — Т. 2. — Стб. 1205–1208:
    - *«дати правду»* — допустити до суду, дозволити виправдатися;
    - *«на правду не вылазити»* — не мати права свідчити або піддаватися очисній процедурі.

#### Епоха 2: XVI–XVII ст. (Староукраїнська / старобілоруська мова ВКЛ)
- **Свідчення історичного словника:**
  - «Словник староукраїнської мови XIV–XV ст.» — К., 1978. — Т. 2. — С. 238:
    - Фіксує перевагу значень «справедливість», «істина», але для законодавчого збірника вже вживається *«право»*, *«статутъ»*.
  - «Словарь древнерусского языка XVI–XVII вв.» (АН СССР / РАН). — М., 1992. — Вып. 18. — С. 112–116:
    - *«правду мовити / сказати»* — давати правдиві показання під присягою.
    - *«правда и справедливость»* — стале парне поєднання (ампліфікація чесності суду).
    - Прикметник *«правдивый»* — дійсний, справжній (про шляхтича), достеменний (про хворобу).

#### Епоха 3: XVII–XVIII ст. (Козацька доба)
- **Свідчення історичного словника:**
  - «Історичний словник українського язика» Є. Тимченка. — К., 1932. — Т. 2. — С. 680:
    - *«правду робити»* — чинити правосуддя, справедливий суд.
    - Вживання слова як збірника законів не зафіксовано; функцію закону несе `право` та `статті`.
