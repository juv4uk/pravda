# МАТРИЦЯ ВІДНОШЕНЬ PACTA (PACTA RELATION MATRIX)
## Семантична геометрія зв'язків: AUTHOR ↔ USER A ↔ USER B

> **Статус документа:** NORMATIVE SPECIFICATION & OPEN QUESTIONS.  
> **Методологічне правило:** Жодного вживання термінів `copyright`, `copyleft`, `GPL`, `MPL`, `EULA`, `intellectual property`.  
> Досліджується виключно **геометрія прав, вольностей та меж дій** між трьома абстрактними суб'єктами.  
> 
> **Статуси тверджень:**
> - `[ACCEPTED]` — аксіоматично прийняте ядро нормативної системи.
> - `[PROPOSED]` — запропоноване правило, що є предметом активного дизайну.
> - `[OPEN]` — невирішене концептуальне питання, що потребує чіткого вибору.

---

### 1. ФУНДАМЕНТАЛЬНИЙ ПРИНЦИП СИМЕТРІЇ: СИМЕТРІЯ КРИТЕРІЮ, А НЕ РОЛЕЙ

```text
РОЛІ НЕ Є ОДНАКОВИМИ:
AUTHOR ≠ USER A ≠ USER B

АЛЕ НОРМАТИВНИЙ КРИТЕРІЙ Є ОДИНАКОВИМ:
CRITERION(AUTHOR) = CRITERION(USER A) = CRITERION(USER B)
```

- `[ACCEPTED]` **Критеріальна симетрія:** Жоден суб'єкт (включно з автором і державною владою) не користується особистим імунітетом від критерію договору. Усі зв'язані одними й тими самими правилами непозбавлення вольностей та заборони агресивного підкорення.
- `[ACCEPTED]` **Диференціація ролей:** Автор є джерелом первинного твору; Користувач A є первинним отримувачем і потенційним модифікатором; Користувач B є наступним реципієнтом. Їхні функції відрізняються, але мірило правомірності їхніх дій — спільне.

### 2. ПАРНІ ВІДНОШЕННЯ: ПОЗИТИВНИЙ ВИМІР (ЩО НАДАЄТЬСЯ ТА ПЕРЕДАЄТЬСЯ)

```text
       AUTHOR (Творець)
          │
          │ створює твір
          ▼
        USER A (Перший набувач)
          │
          │ користується / змінює / передає далі
          ▼
        USER B (Наступний набувач)
```

#### 2.1. AUTHOR ➔ USER A (Первинне надання)
- `[ACCEPTED]` **Право дії:** USER A одержує право виконувати твір, вивчати його внутрішню будову, модифікувати його для власних потреб та створювати похідні твори.
- `[ACCEPTED]` **Вольність від свавілля:** USER A одержує захист від раптового одностороннього позбавлення наданого права добросовісного користування.
- `[PROPOSED]` **Право поширення:** USER A одержує право передавати примірники твору (як автентичні, так і модифіковані) будь-якій третій стороні (USER B).

#### 2.2. USER A ➔ USER B (Передача далі)
- `[PROPOSED]` **Збереження обсягу прав:** USER B при отриманні твору від A набуває можливості користуватися, досліджувати та змінювати твір.
- `[OPEN]` **Механіка спадкоємності вольностей:**
  - *Варіант 1 (Повна непорушність / Invariant Transmission):* USER A в принципі не має права передати твір особі B без передачі повної свободи його дослідження та модифікації.
  - *Варіант 2 (Локальна автономія / Permissive Transmission):* USER A може передати твір B на будь-яких умовах, але первинний твір залишається вільним у джерелі.
  - *Варіант 3 (Розділення на твір і зміни):* Первинна частина твору завжди зберігає вольності для B, а щодо власних доданих змін A сам визначає умови передачі.

#### 2.3. AUTHOR ↔ USER A (Взаємні обов'язки)
- `[ACCEPTED]` **Зв'язаність автора власним словом:** AUTHOR не може оголосити умови публічного договору, а згодом заднім числом оголосити добросовісного користувача A свавільним порушником.
- `[ACCEPTED]` **Межа дій користувача A:** USER A, користуючись наданим твором, бере на себе обов'язок не застосовувати його як засіб насильницького утиску інших.
- `[PROPOSED]` **Відсутність особистих претензій до автора:** USER A не має права вимагати від AUTHOR індивідуального обслуговування, гарантій успіху чи відповідальності за наслідки власного використання.

#### 2.4. USER A ↔ USER B (Межі дій посередника)
- `[PROPOSED]` **Заборона фальсифікації походження:** USER A не має права видавати твір автора за власний або видаляти свідчення про первинного творця.
- `[OPEN]` **Обов'язок передачі засобів пізнання (Source/Readable form):**
  - Чи зобов'язаний A при передачі корисного результату передати B повну можливість бачити внутрішню будову, чи B одержує лише право діяти з тим, що йому фактично надано?

#### 2.5. AUTHOR ➔ USER B (Прямий зв'язок чи транзитивність?)
- `[OPEN]` **Характер зв'язку між автором і кінцевим користувачем:**
  - *Модель прямого зв'язку (Direct Bond):* USER B одержує права і вольності безпосередньо від первинного автора за фактом отримання твору. Посередник A є лише перевізником/кур'єром.
  - *Модель ланцюгової передачі (Transitive Chain):* AUTHOR передає права особі A ➔ особа A передає права особі B. Якщо A порушив умови, ланцюг може розриватися, якщо закон чи договір прямо не захищає добросовісного набувача.

### 3. НЕГАТИВНИЙ ВИМІР: МЕЖІ, ЗАБОРОНИ ТА ТЕСТОВІ ПИТАННЯ

#### 3.1. Що може і чого не може робити USER A щодо твору?

| Дія USER A | Статус у PACTA | Нормативне обґрунтування |
| :--- | :--- | :--- |
| **Закрити власні модифікації від інших?** | `[OPEN]` | Головний вододіл: чи вимагає PACTA обов'язкової відкритості змін, чи захищає лише свободу первинного твору? |
| **Одержувати винагороду / продавати примірники?** | `[ACCEPTED]` | ТАК. Платне поширення чи компенсація за працю не є утиском вольностей. |
| **Додати власні додаткові умови до свого сервісу/пакета?** | `[PROPOSED]` | ТАК щодо власних дій, але НІ, якщо це блокує базові вольності реципієнта щодо Covered Code. |
| **Не передавати засоби дослідження (source form)?** | `[OPEN]` | Потребує рішення: чи є приховування знання порушенням вольності? |
| **Поєднати твір із незалежними сторонніми творами?** | `[ACCEPTED]` | ТАК. Поєднання не змінює природу незалежного стороннього твору. |
| **Використати твір для агресії, тортур чи репресій?** | `[ACCEPTED]` | **КАТЕГОРИЧНО ЗАБОРОНЕНО.** Це пряме порушення нормативного критерію договору. |

#### 3.2. Що може і чого не може робити AUTHOR щодо твору?

| Дія AUTHOR | Статус у PACTA | Нормативне обґрунтування |
| :--- | :--- | :--- |
| **Змінити умови для своїх майбутніх версій твору?** | `[ACCEPTED]` | ТАК. Творець має право публікувати нові праці під іншими умовами. |
| **Відкликати вже надані вольності на вже переданий твір?** | `[ACCEPTED]` | **НІ.** Свавільне одностороннє відкликання на шкоду добросовісному набувачу є порушенням. |
| **Мати виняткові права понад нормативним критерієм?** | `[ACCEPTED]` | **НІ.** Автор є стороною договору, а не сувереном понад ним. Якщо автор сам порушує засади неагресії — він підпадає під той самий критерій порушення. |

### 4. АУДИТ ПРИПУЩЕНЬ: ЩО Є АКСІОМОЮ, А ЩО ПРИХОВАНИМ МЕХАНІЗМОМ?

Проведемо строгу демаркацію наших власних формулювань:

```text
┌─────────────────────────────────────────────────────────────────────────┐
│              АНАЛІТИЧНИЙ АУДИТ НОРМАТИВНИХ ТВЕРДЖЕНЬ                    │
├─────────────────────────────────────────────────────────────────────────┤
│ 1. «Один і той самий критерій для всіх сторін»                         │
│    └── СТАТУС: [ACCEPTED]                                               │
│    └── ПРИРОДА: Справжня аксіома симетрії та захисту від тиранії.       │
├─────────────────────────────────────────────────────────────────────────┤
│ 2. «Автор зобов'язаний бути стороною договору і не стояти понад ним»   │
│    └── СТАТУС: [ACCEPTED]                                               │
│    └── ПРИРОДА: Нормативна відмова від феодального пожалування (grant). │
├─────────────────────────────────────────────────────────────────────────┤
│ 3. «Одержана вольність не може бути використана для утиску інших»       │
│    └── СТАТУС: [ACCEPTED]                                               │
│    └── ПРИРОДА: Етико-правова межа свободи (neminem laedere).           │
├─────────────────────────────────────────────────────────────────────────┤
│ 4. «Вольності передаються непорушно downstream (User A -> User B)»      │
│    └── СТАТУС: [PROPOSED / OPEN MECHANISM]                              │
│    └── ПРИРОДА: Це НЕ універсальна аксіома свободи, а КОНКРЕТНИЙ        │
│        НОРМАТИВНИЙ ВИБІР (близький до спадкоємності copyleft).           │
│        Він потребує свідомого узгодження: наскільки далеко сягає цей     │
│        ланцюг і чи охоплює він модифікації користувача A.               │
└─────────────────────────────────────────────────────────────────────────┘
```

Ця матриця стає первинною специфікацією PACTA: вона очищена від легалістських штампів і дає нам математичну карту відносин між учасниками.
