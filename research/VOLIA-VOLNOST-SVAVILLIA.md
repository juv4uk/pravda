# ДОСЬЄ: ВОЛЯ, ЗВ'ЯЗАНА ВОЛЯ, ПЛІДНА ВОЛЯ ТА СВАВІЛЛЯ
## Онтологія вольності, динаміка влади та геометричний тест на зміну відношень

> **Статус:** `[PHILOSOPHICAL-FOUNDATION]` · `[NORMATIVE-AXIOMATICS]`  
> **Мета:** Дослідити фундаментальну межу між простою здатністю діяти (`ВОЛЯ`), захищеним простором незалежності (`ВОЛЬНІСТЬ`), синергійним розширенням можливостей (`ПЛІДНА ВОЛЯ`) та виникненням асиметрії підкорення (`СВАВІЛЛЯ`).

---

### І. ТРИ СТАНИ ВОЛІ ТА ЇХНЯ АНТИТЕЗА

Воля сама по собі є нейтральною спроможністю діяти. Її етично-правова та суспільна якість визначається тим, **як вона змінює відношення між суб'єктами**:

```text
                                     ВОЛЯ
                         (нейтральна здатність діяти)
                                      │
          ┌───────────────────────────┼───────────────────────────┐
          ▼                           ▼                           ▼
    1. ПРОСТА ВОЛЯ             2. ЗВ'ЯЗАНА ВОЛЯ            3. ПЛІДНА ВОЛЯ
┌────────────────────────┐  ┌────────────────────────┐  ┌────────────────────────┐
│ «Я можу діяти          │  │ «Я можу діяти,         │  │ «Моя дія не лише       │
│  в межах наданого,     │  │  але свідомо не можу   │  │  зберігає вольності,   │
│  без огляду на стан    │  │  перетворити це право  │  │  а й збільшує спільний │
│  наступного».          │  │  на односторонню владу │  │  простір можливостей   │
│                        │  │  над іншим».           │  │  для інших».           │
└────────────────────────┘  └────────────────────────┘  └────────────────────────┘
          │                           │                           │
          │                           ▼                           ▼
          │                 [ВЗАЄМНІСТЬ ТА ЗАХИСТ]       [СИНЕРГІЯ ТА БЛАГО]
          │
          ▼ (при спробі розширити себе коштом іншого)
    4. СВАВІЛЛЯ (ARBITRARY DOMINATION)
┌────────────────────────────────────────────────────────┐
│ «Моє право збільшується через зменшення волі іншого;   │
│  інший стає залежним від мого одностороннього рішення».│
└────────────────────────────────────────────────────────┘
```

### ІІ. ОПЕРАЦІЙНІ ВИЗНАЧЕННЯ ТА СТРУКТУРНИЙ КАСКАД

Розвиток правовідношення розгортається через послідовний каскад:

```text
ВОЛЯ (первинна спроможність)
  ↓
ДІЯ (здійснення вибору / зміна коду)
  ↓
ВІДНОШЕННЯ (виникнення зв'язку з іншими учасниками)
  ↓
ЗАЛЕЖНІСТЬ (виникнення чутливості становища іншого)
  ↓
ВЛАДА (спроможність визначати межі можливостей іншого)
  ↓
  ├─ ЗВ'ЯЗАНА ВЛАДА (визначена взаємним правом і підзвітна процедурі)
  └─ СВАВІЛЬНА ВЛАДА (одностороння здатність визначати практичний простір дій іншого без симетрії)
```

1. **ВОЛЯ (Voluntas / Agency):**
   - Первинна здатність суб'єкта здійснювати дію, обирати напрям руху та змінювати стан об'єкта.

2. **ВОЛЬНІСТЬ (Libertas / Protected Sphere):**
   - Стан, за якого можливість суб'єкта діяти **не залежить від необмеженого приватного розсуду іншого**. Це не просто перелік формально дозволених дій, а гарантована відсутність одностороннього підкорення.

3. **ЗВ'ЯЗАНА ВЛАДА (Bound Authority):**
   - Влада, межі якої наперед визначені взаємним правом і договором; носій влади підпорядкований тому самому критерію, який застосовує до інших, і не є суддею у власній справі.

4. **СВАВІЛЬНА ВЛАДА (Arbitrary Domination):**
   - Одностороння здатність визначати практичний простір дій іншого без симетричної підзвітності. Свавілля виникає не лише тоді, коли право формально скасовується, а й тоді, коли технічний або юридичний контроль усуває практичну можливість його здійснення.

5. **ПЛІДНА ВОЛЯ (Fruitful Agency / Generative Freedom) [ДОСЛІДНИЦЬКА ГІПОТЕЗА]:**
   - Форма дії, за якої виникають нові практичні можливості для спільноти без перетворення інших на залежних від волі первинного суб'єкта.

### ІІІ. КОНЦЕПТУАЛЬНА МОДЕЛЬ ЗМІНИ ВІДНОШЕНЬ (НЕКІЛЬКІСНА ОЦІНКА)

> [!NOTE]
> **[CONCEPTUAL MODEL — NOT QUANTITATIVE]**  
> Нижченаведені відношення не є математичними формулами розрахунку блага, оскільки одиниці «вольності» чи «блага» не мають кількісного виміру. Це **концептуальна геометрія зміни статусів та доступних дій**:
> - **$\Delta\text{Вольність}$** = зміна множини реально доступних правомірних дій/можливостей суб'єкта.
> - **$\Delta\text{Влада}$** = зміна здатності одного суб'єкта односторонньо визначати правове становище або залежність іншого.

```text
СВАВІЛЛЯ виникає там, де:
  1) З'являється одностороння влада над становищем іншого;
  2) Створюється залежність іншого від приватного розсуду володаря;
  3) Відсутнє взаємне або нормативно виправдане обмеження.

ОБМЕЖЕННЯ ВОЛІ ≠ СВАВІЛЛЯ:
Не всяке звуження волі є свавіллям. Заборона видаляти ім'я автора чи обов'язок
відкрити вихідний стан covered file звужують волю передавача, але вони є
взаємним захистом чужого права або умовою збереження спільного статусу твору.
```

### IV. АНАЛІЗ ВІДНОШЕНЬ: «ЧИЯ СВОБОДА, У ЯКИЙ МОМЕНТ І ЩОДО КОГО?»

Суперечка між ліцензійними режимами розкривається не через моральну оцінку, а через аналіз спрямування волі:

```text
              Ланцюг передання:
              B (Автор) ───надає───► A (Модифікатор) ───передає───► C (Одержувач)
```

1. **Питання до відношення A → C:**
   - Суб'єкт $A$ одержав свободу дій від $B$.
   - **Питання:** Чи передбачає режим ліцензування, що у свободу дій $A$ входить можливість передати твір суб'єкту $C$ на умовах, які виключають для $C$ ті дії, які міг здійснювати $A$?

2. **Характеристика Permissive (MIT):**
   - Максимізує дискрецію теперішнього суб'єкта $A$: $A$ має право вільно обирати режим для своєї копії чи похідного продукту (включно із закриттям вихідного тексту або накладанням пропрієтарних обмежень на $C$).
   - *Структурний наслідок:* Ступінь вольності суб'єкта $C$ стає повністю залежним від приватного рішення $A$.

3. **Характеристика Strong Copyleft (GPL):**
   - Накладає умову на передання (conveyance): суб'єкт $A$ зобов'язаний надати $C$ той самий обсяг прав і вихідний стан коду, який одержав сам від $B$.
   - *Структурний наслідок:* Частину дискреції $A$ щодо зміни умов зв'язано заради симетрії статусу $C$.

4. **Нормативна позиція PACTA / VOLNOST:**
   - Ми висуваємо принцип: **Самообмеження дискреції $A$ (відмова від одностороннього позбавлення прав $C$) розглядається як умова існування більшої взаємної вольності**.
   - Водночас межа проводиться чітко: захист прав $C$ щодо переданого твору не повинен перетворюватися на владу первинного автора $B$ односторонньо підпорядковувати незалежні та суміжні твори, які $A$ створив власною працею поруч.

### V. ВІДКРИТЕ ДОСЛІДНИЦЬКЕ ПИТАННЯ ДЛЯ PRAVDA

> **Коли самообмеження волі одного перестає бути тягарем і стає каталізатором плідної волі для всіх?**

Цей вектор відкриває нову фазу дослідження: аналіз конкретних точок, де виникає спокуса свавілля (закриття патентів, Tivoization, API lock-in, захоплення форків), і проектування таких правил договору `PACTA`, які роблять збереження вольностей природним та економічно життєздатним.
