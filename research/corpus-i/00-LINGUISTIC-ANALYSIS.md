# ЛІНГВІСТИЧНИЙ (СЕМАНТИЧНИЙ) АНАЛІЗ КОРПУСУ I: РУСЬКЕ ПРАВО (XI–XII ст.)

**Джерела:** Руська Правда (Коротка, Розширена, Скорочена редакції), Устави Володимира та Ярослава, смоленська/новгородська уставні грамоти  
**Методологія:** Реконструкція правосвідомості виключно через власну термінологію джерел; заборона анахроністичних категорій («права людини», «суб'єктивне право»).

## 1. БАЗОВА СЕМАНТИЧНА МАПА ЛЕКСИКИ

### 1.1. Ключові терміни та їхні сенси

| Термін джерела | Етимологія / Корінь | Сенс у тексті | Функція в правовій архітектурі |
|---|---|---|---|
| **ПРАВДА** (*правъ* — прямий, істинний, справедливий) | ПІЄ *prā́vas* «правильний, прямий» | 1) Закон, узаконений звичай (*«Правда Руська»*)<br>2) Судова істина/вирішення (*«дати правду залізо»*)<br>3) Незмінна нормативна база | Заміна абстрактного «права» — не суб'єктивна прерогатива, а об'єктивний порядок |
| **СУДЪ** | ПІЄ *sū́d* «розсуд, вирішення» | Конкретний процес між *їстцем* (позивачем) та відповідачем; невідділений від особи князя/єпископа/тіуна | Немає поняття «правосуддя» як окремої інституції — лише судовий акт |
| **ОБИДА** | ПІЄ *obida* «обида, образа, збиток» | Будь-яке порушення нормативного стану: моральна кривда + майновий збиток. Не «злочин проти держави», а особиста образа | Категорія делікта, що запускає компенсаційну машинерию |
| **ВІРА** | ПІЄ *virъ* «віра, довіра; штраф, стягнення» | Державний штраф князю за вбивство вільного мужа (80/40 грн) | Фіскальна санкція, монополія князя на насилля |
| **ДИКА ВІРА** | *дикий* — «дикий, невідомий» + *вира* | Колективний викуп громади (*верви*) за невідомого вбивцю | Колективна відповідальність, substitutio responsibilitatis |
| **ГОЛОВЩИНА / ГОЛОВНИЦТВО** | *голова* — «голова, людина, голова роду» | Приватна компенсація родичі вбитого — заміна кровної помсти | Заміна помсти грошовим еквівалентом |
| **ПРОДАЖ** | *продати* — «віддати за ціну» | Штраф на користь князя за менші злочини (побої, крадіжка: 12/3 грн) | Фіскальна санкція за делікти нижчої тяжкості |
| **УРОК** | *врокъ* — «вирік, встановлення, податок» | Фіксований податковий збір, мито, компенсація за працю (*«Урок мостників»*) | Нормативне ціноутворення влади |
| **ПОКОН** | *поконъ* — «закінчення, встановлення, норма» | Звичаєве встановлення, обов'язковий припис (*«Покон вирный»*) | Закріплення звичаю як обов'язкового |
| **РЯД** | *рядъ* — «порядок, договір, умова» | Договір про умови залежності/служби (*ряд закупа*, *ряд князя з містом*) | Єдиний договірний інститут, що породжує взаємні обов'язки |
| **ЗАКУП** | *за-купити* — «взяти в закладу/борг» | Боржник, що відробляє покупку; має процесуальні гарантії (не холоп) | Паросток договірної правової сфери |
| **СМЕРД** | ПІЄ *sъmrdъ* «селянин-общинник, вільний але залежний» | Селянин, земля якого переходить князю при відсутності синів | Залежний статус із обмеженим захистом |
| **ХОЛОП / ЧЕЛЯДЬ / РОБА** | *холопъ* (запозичення з іран.?), *челядь* «дворова», *роба* «раб» | Об'єкти власності; не можуть свідчити; відповідальність несе господар | Повна відсутність правосуб'єктності |
| **ІЗГОЙ** | *из-гати* — «вигнати, вилучити» | Людина поза соціальним захистом роду/стану; 40 грн або патронат церкви | Маргінальний статус, екстерналізація відповідальності |
| **СОРОМ / ОБИДА** | *соромъ* «стид, ганьба»; *обида* | Матеріально відшкодовувана кривда гідності; тариф залежить від стану | Захист честі через компенсацію, не через заборону |
| **НЕМОЖНА ПОМСТА** | *помщити* | Коротка Правда: діє; Розширена: заборонена (*«отложиша оубиение за голову»*) | Перехід від самосуду до державної монополії на насилля |

## 2. СЕМАНТИЧНІ ЗСУВИ: ВІД КОРОТКОЇ ДО РОЗШИРЕНОЇ РЕДАКЦІЇ

| Інститут | Коротка Правда (43 ст.) | Розширена Правда (121 ст.) | Семантичний зсув |
|---|---|---|---|
| **Помста** | Діє (*«мстить брат за брата»*) | Заборонена державою (*«отложиша оубиение за голову»*) | Монополізація насилля державою |
| **Вбивство** | Тариф 40 грн ( уніфікований) | Станова градація: 80/40/12/5/6 грн | Статусна диференціація ціни життя |
| **Тілесні ушкодження** | Тариф за «обиду» (12 грн за бороду) | Концепція виправданої самооборони; напіввіра за каліцтво | Поява суб'єктивного елемента у кваліфікації |
| **Докази** | *Видок* (очевидець), ізвід | *Видок* + *Послух* (репутація) + *Ордалії* (залізо, вода, рота) | Диференціація епістемологічних режимів |
| **Закуп** | Не згадується | Статус із гарантіями: не бити без вини, не продавати в холопи, право до князя | Поява договірної сфери всередині залежності |
| **Княжий фіск** | Формується випадково | Чітко: віра + головщина + продаж + урок | Інституціоналізація фіскальної влади |

## 3. МОРФОЛОГІЧНА ІНТЕГРАЦІЯ ЗАПОЗИЧЕНЬ (ВІЗАНТІЯ → РУСЬ)

| Візавійський термін (Номоканон) | Руський еквівалент | Механізм адаптації |
|---|---|---|
| *κανών* (канон) | **ПРАВДА** | Не позичка, а семантичне еквівалентування: *правда* = «правильний порядок» |
| *ἔκδικος* (епцдок/суд'я) | **ТИУН / МЕЧНИК** | Рідне слово для адміністративно-судового чиновника |
| *πεντηκοστή* (п'ятдесятина/десятина) | **ДЕСЯТИНА** | Калька через церковну адміністрацію |
| *ἐξουσία* (влада, юрисдикція) | **СУД / ВОЛЯ КНЯЗЯ** | Семантичне розширення рідного *воля* |
| *αὐτοκατάκρισις* (самовинувачення) | **РОТА / ІЗВІД** | Рідний інститут присяги замість Rimskого *confessio* |
| *δουλεία* (рабство) | **ХОЛОПСТВО / ЧЕЛЯДСТВО** | Власна стратифікація залежності (не калька) |

**Висновок:** Руська правова лексика не калькує візантійську — вона **селективно асимілює** концепції через рідні корені (*правда, суд, ряд, обида, воля*), створюючи автономну семантичну систему.

## 4. СТАТУСНА СЕМАНТИКА: ІЄРАРХІЯ СУБ'ЄКТІВ

```
[КНЯЗЬ / ДВІР] → Огнищанин, Тівун, Конюший (віра 80) — привілейований елітний статус
    │
[ВІЛЬНІ МУЖІ] → Русин, Гридин, Купець, Мечник, Словенін (віра 40) — повноцінні суб'єкти суду
    │
[НАПІВВІЛЬНІ] → Закуп, Рядович (5 грн) — договірна залежність з процесуальним мінімумом
    │
[ЗАЛЕЖНІ СЕЛЯНИ] → Смерд (5 грн паню/князю; земля князю без синів) — статус-об'єкт
    │
[НЕВІЛЬНИКИ] → Холоп, Челядин, Роба (5-6 грн як за худобу) — повна відсутність суб'єктності
    │
[ПОЗАСИСТЕМНІ] → Ізгой, Прощенники (40 грн або патронат церкви) — екстерналізація відповідальності
```

**Ключова семантика статусів:**
- **Життя** = грошовий еквівалент (віра/головщина), не недоторканне благо
- **Честь** = тарифоване значення (*сором* = 5 зл. до 1 ср. залежно від стану)
- **Воля** = договірна умова (*ряд*), не автономна здатність

## 5. ПРОТОДОГОВІРНІСТЬ «РЯДУ» ЯК СЕМАНТИЧНИЙ ЯКІР

**Ряд** (*рядъ* — порядок, договір) — єдиний термін, що поширюється через епохи:

| Епоха | Форма *ряду* | Семантика |
|---|---|---|
| Русь (XI–XII) | *Ряд закупа*, *ряд князя з городом* | Договір про умови залежності/податків |
| ВКЛ (XVI) | *Привілей*, *устав*, *стаття* | Монарший акт + сеймова ратифікація |
| Гетьманщина (XVII) | *Стаття*, *договір*, *універсал* | Договірна стаття гетьмана з царем/королем |
| Конституції (XVIII–XX) | *Стаття конституції*, *пункт універсалу* | Нормативний акт вищої сили |

**Семантична стала:** *ряд* — це **формальне закріплення взаємних обов'язків**, яке створює *процесуальну сферу* (право на скаргу, захист від свавілля) на противагу сеньйоріальній власності.

## 6. ВИСНОВКИ ЛІНГВІСТИЧНОГО АНАЛІЗУ КОРПУСУ I

### 6.1. Домінантна модель: **Tariffed Liability** (тарифна відповідальність)
- Немає лексики для «суб'єктивного права», «недоторканності», «автономії»
- Вся лексика орієнтована на **матеріальний еквівалент** (віра, головщина, продаж, урок, припис)
- Злочин = «обида» (порушення рівноваги), що ліквідується грошовою платою

### 6.2. Три семантичні «остови», що перейшли в наступні епохи
1. **РЯД / ДОГОВІР** → основа привілеїв ВКЛ, Магдебурзького права, гетьманських статей
2. **СОРОМ / ОБИДА** → шляхетська/козацька «лицарська честь», концепція гідності
3. **СУД / ВИДОК / РОТА** → процесуальна культура Статутів ВКЛ, Трибуналу

### 6.3. Відсутні лексичні вакансії (що НЕ існувало)
- *право* (як суб'єктивне) — немає
- *вольність* (як універсальна) — немає (лише *вільний чоловік* проти холопа)
- *недоторканність* — немає
- *суверенітет особи* — немає
- *гражданство* — немає

### 6.4. Лінгвістична діагностика анахронізму
Будь-яке вживання термінів **«права людини», «природні права», «суверенна невідчужуваність особи»** для XI–XII ст. — це **грубий лексикальний анахронізм**, оскільки у текстах відсутні відповідні лексичні одиниці (лемми) і семантичні схеми.

## 7. ПРИЛАДДЯ ДЛЯ НАСТУПНИХ КОРПУСІВ

При аналізі Корпусів II–XII використовувати цей **семантичний фільтр**:
1. Виокремлювати **власні лемми** джерела (не вживати модерних термінів як категорій)
2. Фіксувати **семантичні зсуви** між редакціями/епохами
3. Відділяти **кальки** (семантичні адаптації) від **позичок** (лексичних запозичень)
4. Відстежувати **перехід термінів** через епохи (*ряд → привілей → стаття → статья конституції*)
5. Класифікувати кожен інститут: **Tariffed Liability** vs **Protected Sphere** vs **Contractual Sphere**
